# Islamic Research & Writing — Salafi Scholarship Only

## When to Use This Skill

Trigger this skill for ANY of the following:
- User asks about Islam, Quran, Hadith, prayer (salah), Aqeedah, Tawheed, Fiqh, Seerah, or comparative religion
- User asks to research, write, create, or update an article/guide/note/document on an Islamic topic
- User asks about what Islam says about X, or what scholars say about X
- User asks about Jesus in Islam, Mary in Islam, prophets, prayer, wudu, fasting, zakat, hajj, bid'ah, bidah, sin, repentance, etc.
- User asks to compare Islamic views with Christianity, Judaism, or other religions
- User mentions "Salafi", "scholars", "fatwa", or asks for Islamic rulings

**Do NOT ask the user "do you want me to use Salafi sources?" — just do it.** This is the default for all Islamic topics.

## Core Principle

**Every claim, ruling, or statement about Islam MUST be directly attributable to a named Salafi scholar.** No fabricating quotes. No guessing references. If a source cannot be found, mark it explicitly as `NOT FOUND FROM SALAFI SOURCE` rather than inventing something.

## Methodology — How to Research

### Step 1: Launch background research agents
For each Islamic topic, launch a background subagent (using `run_subagent` with `is_background: true`) to gather information. The agent must:

1. **Search the approved websites** listed above for the topic.
2. **Find verbatim quotes** from named scholars — not paraphrases. Include the scholar's name, book title, volume/page if available, and the source URL.
3. **Get exact hadith references** — collection name, book/chapter, hadith number. Include **al-Albani's grading** where possible (Sahih, Hasan, Da'if, etc.).
4. **Get exact Quran references** — Surah name, Surah number, ayah number.
5. **Mark anything that cannot be sourced to a Salafi scholar** as `NOT FOUND FROM SALAFI SOURCE` — do NOT fabricate.
6. **Write findings to a research file** in `C:\Users\ahmed\research-notes\` with the naming convention `research_<topic>_salafi.md`.

### Step 2: Write the article/guide/note
Based on the research, write the document with:
- **Verbatim quotes** from the scholars, in blockquotes, with the scholar's name and source cited.
- **Exact Quran references** in the format: (Quran, Surah [Name] [number]:[ayah])
- **Exact hadith references** in the format: (Sahih al-Bukhari, Hadith [number]; Sahih Muslim, Hadith [number]) — include al-Albani's grading where relevant.
- **A "Sources" section** at the end listing all books, scholars, and URLs used.
- **Honesty about gaps** — if something was not found from a Salafi source, say so explicitly. Do not fill gaps with guesses.

### Step 3: Save the output
- **Research files** go to: `C:\Users\ahmed\research-notes\research_<topic>_salafi.md`
- **Articles/guides/documents** go to: `C:\Users\ahmed\research-notes\<topic>.md`
- Tell the user where the file was saved.

### Step 4: Verify and fix ALL source links
Before opening the article in a markdown preview app, you MUST verify every single URL/source link in the article AND the background research files. This is a critical quality-control step.

1. **Extract ALL URLs** from the article (and background research files if they will be pushed). Every single URL — in the body text, source citations, and the Sources section at the end.

2. **Visit each URL** using the `webfetch` tool to verify it loads correctly and points to the expected content.

3. **Fix broken/incorrect URLs:**
   - **binbaz.org.sa links are ALWAYS broken if they don't include the full Arabic slug.** For example, `https://binbaz.org.sa/fatwas/14402/` is BROKEN — it must be the full URL like `https://binbaz.org.sa/fatwas/14402/%D8%AD%D9%83%D9%85-%D9%85%D9%86-%D9%8A%D9%86%D9%83%D8%B1-%D8%A7%D8%B3%D8%AA%D9%88%D8%A7%D8%A1-%D8%A7%D9%84%D9%84%D9%87-%D8%B9%D9%84%D9%89-%D8%A7%D9%84%D8%B9%D8%B1%D8%B4`. When you visit the short URL with webfetch, it will redirect to the full URL — use that full URL as the replacement.
   - For any other broken URL (404, redirect to wrong page, site down, content doesn't match), search the web to find the correct URL and replace it.
   - If a URL cannot be fixed, mark it as `[BROKEN LINK — could not verify]` in the file so the user knows.

4. **Use parallel subagents** to speed up the process if there are many URLs across multiple files. Each subagent can handle a group of files — extract URLs, check them, and fix broken ones.

5. **Report to the user** how many links were checked, how many were broken, and how many were fixed.

**This step is MANDATORY.** Never skip it. Every single link must be verified before the article is considered complete.

## What to NEVER Do

1. **NEVER fabricate a quote** and attribute it to a scholar. If you cannot find the exact quote, say `NOT FOUND FROM SALAFI SOURCE`.
2. **NEVER guess a hadith reference.** If you cannot verify the collection and number, do not invent one.
3. **NEVER use non-Salafi sources** (e.g., Sufi, Shia, modernist, or unknown websites) as the primary source for rulings. If a non-Salafi source happens to cite a Salafi scholar, trace it back to the original scholar.
4. **NEVER present a personal opinion as a scholarly position.** Always attribute to a named scholar.
5. **NEVER mix methodologies.** Stick to the Salafi methodology consistently.
6. **NEVER say "scholars say" without naming which scholar.** Always name the scholar and cite the book/source.
7. **NEVER use short binbaz.org.sa URLs.** URLs like `https://binbaz.org.sa/fatwas/14402/` are BROKEN — they must include the full Arabic slug (e.g. `https://binbaz.org.sa/fatwas/14402/%D8%AD%D9%83%D9%85-%D9%85%D9%86-%D9%8A%D9%86%D9%83%D8%B1-...`). Always visit the URL with webfetch to get the full redirected URL before saving it in a file.
8. **NEVER leave a source link unverified.** Every URL in the final article must be visited and confirmed to work before the article is considered complete.

## Tone & Style

- **Respectful and direct.** Use "(may Allah have mercy on him)" for deceased scholars, "(may Allah preserve him)" for living scholars.
- **Use the ﷺ symbol** after the Prophet's name.
- **Use (عليه السلام)** after the names of other prophets.
- **Use (may Allah be pleased with him/her)** after the names of Companions.
- **Transliterate Arabic terms** and provide English meanings the first time they appear.
- **Include Arabic text** for Quran verses, hadith, and adhkar where possible, alongside transliteration and translation.
- **Be honest about differences of opinion** among the scholars when they exist — do not pretend there is unanimity when there is not. But present the strongest view according to the evidence.
